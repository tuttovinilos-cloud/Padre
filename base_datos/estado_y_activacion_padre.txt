PROCEDIMIENTO DE PRIMER ADMINISTRADOR
1. Abrir https://supabase.com/dashboard/project/cuzswxryqvbguntjvhsa/auth/users
2. Crear o invitar al usuario autorizado, con correo real y contraseña nueva.
3. Copiar su UUID de usuario (NO su clave).
4. En el SQL Editor de PADRE, ejecutar (sustituyendo solo UUID y nombre):

BEGIN;
WITH alta AS (
 INSERT INTO public.operadores (auth_user_id,nombre,activo)
 VALUES ('REEMPLAZAR-UUID-DEL-AUTH-USER','Administrador Padre',true)
 RETURNING id
)
INSERT INTO public.operadores_roles (operador_id,rol_id)
SELECT alta.id,roles.id
FROM alta CROSS JOIN public.roles roles WHERE roles.codigo='administrador';
COMMIT;

Este procedimiento es solo para un usuario de confianza. No se debe
automatizar como autorregistro del navegador.
